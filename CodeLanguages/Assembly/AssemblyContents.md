# Assembly Directory

[Return to Code Directory](/CodeLanguages/ReadMe.md)

Main directory of Assembly code language (NASM)
This directory is split by type of assembly language.

### FASM (Flat Assembler)
Anything built with this language can be run on both Windows and Linux with the correct program

#### MASM (Microsoft Assembler)
Anything built with this language can be run on Windows only with the correct program
* Note there is two different verions, one that supports 16/32 bit and one that supports 64 bit. All programs in this directory will be built with the 16/32 bit version for greater compatibility
